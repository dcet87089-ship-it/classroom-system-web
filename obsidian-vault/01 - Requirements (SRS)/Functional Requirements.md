# ⚙️ ข้อกำหนดเชิงฟังก์ชัน (Functional Requirements - FR)

เอกสารนี้ระบุฟังก์ชันการทำงานทั้งหมดของระบบ CheckIn โดยแบ่งตามส่วนประกอบหลักและบทบาทผู้ใช้

---

## 1. การจัดการผู้ใช้งาน (User Management)

| รหัส | รายการฟังก์ชัน | คำอธิบายรายละเอียด |
| :--- | :--- | :--- |
| **FR-USER-01** | เลือกระดับสิทธิ์ | ผู้ใช้สามารถเลือกว่าตนเองเป็น "อาจารย์ (Teacher)" หรือ "นักศึกษา (Student)" ได้ที่หน้าแรก |
| **FR-USER-02** | ระบุข้อมูลประจำตัว | ผู้ใช้ต้องกรอก Email, ชื่อ-นามสกุล, และรหัสประจำตัว (รหัสนักศึกษา หรือ รหัสบุคลากร) |
| **FR-USER-03** | จดจำข้อมูลผู้ใช้ | ระบบทำการบันทึก Session ใน Local Storage และส่งข้อมูลเชื่อมต่อกับฐานข้อมูลผ่าน `/api/auth/login` |
| **FR-USER-04** | ออกจากระบบ (Logout) | ผู้ใช้สามารถกดออกจากระบบเพื่อล้างข้อมูลเซสชันและกลับสู่หน้าหลัก |

---

## 2. ระบบสำหรับอาจารย์ (Teacher Features)

| รหัส | รายการฟังก์ชัน | คำอธิบายรายละเอียด |
| :--- | :--- | :--- |
| **FR-TCH-01** | ดึงพิกัดอาจารย์ | ระบบดึงพิกัดละติจูด/ลองจิจูดของอาจารย์ผ่าน Web Geolocation API อัตโนมัติ เพื่อใช้เป็นศูนย์กลางห้องเรียน |
| **FR-TCH-02** | เปิดห้องเรียน (Start Class) | ระบุรหัสวิชา (Course Code) และชื่อวิชา (Course Name) เพื่อสร้างห้องเรียนใหม่ |
| **FR-TCH-03** | สุ่มรหัสเข้าห้อง 6 หลัก | ระบบสุ่มรหัสตัวเลข 6 หลักที่ไม่ซ้ำกับห้องที่กำลังเปิดอยู่ |
| **FR-TCH-04** | สร้าง Dynamic QR Code | ระบบสร้าง QR Code จากรหัสห้องเรียนเพื่อให้นักศึกษาสแกน |
| **FR-TCH-05** | แสดงรายชื่อนักศึกษา Real-time | แสดงรายชื่อนักศึกษาที่อยู่ในห้องเรียน พร้อมสถานะการเชื่อมต่อ และระยะห่างเป็นเมตร |
| **FR-TCH-06** | ตรวจจับการขาดหายของสัญญาณ | หากนักศึกษาไม่ส่ง Heartbeat เกิน 20 วินาที ระบบจะแสดงสถานะจุดสีเหลือง (สัญญาณขาดหาย) |
| **FR-TCH-07** | เตะนักศึกษาออกจากห้อง | อาจารย์สามารถกดลบนักศึกษาที่ไม่เกี่ยวข้องออกจากห้องเรียนได้ทันที และส่งสัญญาณตัดการเชื่อมต่อไปยังอุปกรณ์นักศึกษา |
| **FR-TCH-08** | ส่งข้อความประกาศในห้อง | อาจารย์สามารถพิมพ์ข้อความในช่องแชทเพื่อกระจายข่าวสารให้นักศึกษาทุกคนในห้องเห็นแบบทันที |
| **FR-TCH-09** | ปิดคลาสและบันทึกประวัติ | เมื่ออาจารย์กดปิดคลาส ข้อมูลนักศึกษาทุกคนจะถูกบันทึกประวัติลงฐานข้อมูลในตาราง `AttendanceHistory` และส่งสัญญาณให้นักศึกษาออกจากห้อง |

## 3. ระบบสำหรับนักศึกษา (Student Features)

| รหัส | รายการฟังก์ชัน | คำอธิบายรายละเอียด |
| :--- | :--- | :--- |
| **FR-STD-01** | เข้าห้องด้วยรหัส 6 หลัก | นักศึกษาสามารถกรอกรหัส 6 หลักของห้องเรียนเพื่อกดเข้าร่วมห้อง |
| **FR-STD-02** | สแกน QR Code เพื่อเข้าห้อง | นักศึกษาสามารถเปิดกล้องของอุปกรณ์เพื่อสแกน QR Code ที่แสดงบนหน้าจออาจารย์ |
| **FR-STD-03** | ตรวจสอบพิกัด GPS ต่อเนื่อง | แอปทำการติดตามพิกัดของนักศึกษาอย่างต่อเนื่องผ่าน `watchPosition` |
| **FR-STD-04** | คำนวณระยะห่างทางภูมิศาสตร์ | คำนวณระยะห่างระหว่างนักศึกษาและอาจารย์ (สูตร Haversine) และแบ่งระดับสถานะ: <br>• $\le 50\text{ m}$: ระยะปลอดภัย (เข้าเรียนสำเร็จ)<br>• $51 - 100\text{ m}$: เริ่มออกห่าง (เฝ้าระวัง)<br>• $> 100\text{ m}$: ห่างเกินระยะ (ขาดเรียน) |
| **FR-STD-05** | ส่งสัญญาณ Heartbeat | นักศึกษาส่งข้อมูลพิกัดและสัญญาณชีพจรไปยังเซิร์ฟเวอร์ทุก 10 วินาที |
| **FR-STD-06** | แชทตอบโต้ในห้องเรียน | นักศึกษาสามารถส่งและรับข้อความในห้องเรียนได้ |
| **FR-STD-07** | จัดการตารางเรียน (Schedule) | เพิ่ม แก้ไข ดูตารางเรียนประจำสัปดาห์ (จันทร์-ศุกร์) พร้อมเวลาและสถานที่ |
| **FR-STD-08** | ดูปฏิทินประวัติการเข้าเรียน | เลือกดูประวัติการเข้าเรียนย้อนหลังตามวันที่ และดูสรุปตัวเลขสถิติ (เข้าเรียน, เฝ้าระวัง, ขาด) |
